Claude says “This conversation is too long to continue”

The message ends “Start a new chat, or remove some tools to free up space.” Here’s how to keep going.

Updated 18 October 2026

In Claude

  1. 1

    Turn off tools you don’t need

    Click the + button in the chat, then Connectors. Switch off the ones this chat doesn’t use, or set Tool access to On demand.

  2. 2

    Keep code execution on

    On paid plans, Claude then summarizes earlier messages as a chat grows. It’s in Settings → Capabilities.

  3. 3

    Ask a new chat to find the old one

    On paid plans, say “Let’s continue where we left off with Northwind pricing.” Claude searches your past chats.

  4. 4

    Use a project

    Files you add to a project are used in every chat inside it.

Sources: length limits, tool access, chat search, projects.

Or with SkyOS

In a new chat, say “continue” and the memory’s name from your Memory page. Claude gets its notes and the last few messages.

SkyOS saves as you chat, so connect it before your next long one. It works on Claude’s Free plan too.
