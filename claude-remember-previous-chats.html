How to make Claude remember previous chats

Claude remembers on its own now. Here’s how to check, and what SkyOS adds.

Updated 18 October 2026

In Claude

Source: chat search and memory.

  1. 1

    Check memory is on

    Settings → Memory → Generate memory from chats. It’s on by default on Free, Pro and Max.

  2. 2

    Let it search past chats

    On paid plans, just ask: “What did we discuss about pricing?” The switch is Search and reference chats, also in Settings → Memory.

  3. 3

    See what it remembers

    Settings → Memory lists each topic. Edit or delete any of them.

  4. 4

    Keep projects apart

    Each project has its own memory.

What SkyOS adds

Exact, dated notes for each project. Say “continue Northwind pricing” and Claude gets that project’s notes and your last few messages.

The same notes work in ChatGPT and Codex.
