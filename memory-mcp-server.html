Run the reference server

Source: modelcontextprotocol/servers on GitHub.

  1. 1

    Add it to your app’s MCP config

    Its command:

    npx -y @modelcontextprotocol/server-memory
  2. 2

    What it keeps

    A knowledge graph of entities, relations and facts, in a local file, memory.jsonl.

  3. 3

    Where it runs

    On your computer. Each app starts its own copy.

Or add SkyOS

A hosted memory MCP server: add its URL, sign in, and each project gets dated notes you can read at app.skyos.ink.

Three tools: skyos_recall, skyos_save and skyos_use_memory. In the MCP Registry as ink.skyos/memory.
